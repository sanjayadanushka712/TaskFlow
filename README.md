# taskflow

tasks:
  Checkout — downloads your repository.
  Set up Python — prepares Python 3.14.
  Install dependencies — installs packages from requirements.txt.
  Start PostgreSQL — provides a clean database for CI.
  Create database tables — prepares the schema.
  Ruff lint check — catches code-quality issues.
  Ruff format check — verifies consistent formatting without changing files.
  Pytest — checks application behavior.
